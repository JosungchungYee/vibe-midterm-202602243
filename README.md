# 카페 메뉴 주문 및 확인 웹앱

## 1. 앱 소개

**카페 메뉴 주문 및 확인 웹앱**은 카페 음료를 키오스크처럼 선택하고 주문할 수 있는 웹앱입니다. 고객은 음료 메뉴를 고른 뒤 옵션 선택 화면에서 아메리카노와 라떼의 Ice/Hot 온도, 샷 추가, 시럽 추가를 선택하고 장바구니에 담아 주문할 수 있습니다. 관리자는 같은 페이지의 관리자 대시보드에서 주문 현황과 메뉴별 재고를 확인하고 제조 완료를 처리할 수 있습니다.

## 2. 주요 기능

- 아메리카노, 라떼, 아이스티, 요거트 스무디, 망고 스무디 등 음료 5종 선택
- 옵션 선택 화면
  - 아메리카노/라떼는 Ice 또는 Hot 중 하나를 필수로 선택
  - 샷 추가 시 500원 추가
  - 시럽 추가는 무료
- 장바구니에 음료 담기, 항목 삭제, 합계 확인
- 옵션 조합별 항목 및 수량별 금액 표시
- 주문 시 재고 차감, 재고가 0인 메뉴 품절 표시
- 관리자 대시보드에서 주문 현황 확인 및 제조 완료 처리
- 관리자 화면에서 메뉴별 남은 재고 확인
- 장바구니, 재고, 주문 데이터를 브라우저 `localStorage`에 저장하여 새로고침 후 복원

## 4. 사용법

1. 메뉴 화면에서 원하는 음료 카드를 선택합니다.
2. 옵션 선택 화면에서 원하는 옵션을 고릅니다. 아메리카노와 라떼는 Ice 또는 Hot을 반드시 선택해야 합니다.
3. 하단에 표시되는 현재 금액을 확인하고 **담기**를 누릅니다. 메뉴 화면으로 돌아갑니다.
4. 메뉴 화면의 **장바구니** 버튼을 눌러 담긴 음료와 옵션, 수량 및 합계를 확인합니다. 필요하면 항목을 삭제할 수 있습니다.
5. 장바구니에서 **주문하기**를 누르면 주문이 접수되고 메뉴별 재고가 차감됩니다.
6. 화면 상단의 **관리자** 버튼을 누르면 관리자 대시보드로 전환됩니다. **주문 현황**에서 주문을 확인하고 해당 주문의 **제조 완료** 버튼을 눌러 완료 처리할 수 있습니다. **메뉴별 재고** 탭에서는 남은 재고를 확인할 수 있습니다.
7. 메뉴 재고가 0개가 되면 메뉴가 품절로 표시되고 선택할 수 없게 됩니다.
